# Сайт-визитка

Сайт-визитка Ивана Орлова, веб-разработчика. Собран на шаблоне [11ty-template](https://github.com/Orles/11ty-template): Eleventy, Vite, Nunjucks, SCSS и TypeScript.

## Запуск

Нужен Node.js `^20.19.0` или `>=22.12.0`.

```bash
npm install
```

```bash
npm run dev
```

Сайт будет доступен на http://localhost:8080. Для продакшен-сборки выполните `npm run build`, готовый сайт появится в папке `_site`.

## Как менять содержимое

Все тексты лежат в [`src/data/resume.ts`](src/data/resume.ts):

- `profile`: имя, должность и вводный текст;
- `skills`: стек по группам;
- `projects`: проекты, поле `url` необязательное: без него проект показывается без ссылки, а `featured: true` добавляет проект в карусель «Избранное»;
- `experience`: опыт работы, секция появится при первой записи;
- `contacts`: контакты, например почта или Telegram.

Кнопка «Сохранить в PDF» открывает печать браузера. Для неё есть отдельные стили, поэтому страница печатается как обычное резюме.
